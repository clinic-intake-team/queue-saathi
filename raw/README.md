# Raw recordings

The folder structure is tracked so it appears after cloning or pulling:

- `setA_chill/`: Set A recordings for speaker `ch`.
- `setA_tm/`: Set A recordings for speaker `tm`.
- `setB_chill/`: Set B recordings for speaker `ch`.
- `setB_tm/`: Set B recordings for speaker `tm`.

Voice files are intentionally ignored. Share them privately and copy them into
the matching folders locally; Git does not distribute the recordings.
